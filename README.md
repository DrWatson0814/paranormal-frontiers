# Paranormal Frontiers

## <u>Project Title:</u>
    Paranormal Frontiers

## <u>Description:</u>
    Paranormal Frontiers is meant to be used as central hub for the preparation, execution, and evaluation of a paranormal investigation. The Home page is meant to be a place where news, and current information about the paranormal community can be viewed. The Gear page, is used for locating, obtaining, and the organization of any needed tools and gear. Investigations page, is used for planning the logistics of the investigation, keeping track of team members and their assigned roles, along with information about the location and its history. Finally, the Research page, is meant to be used as a means to collect, organize, and evaluate any data that may be collected or to understand anything that may be learned during the course of the investigation.

## <u>Installation Instructions:</u>
1. You must have Node.js installed.
2. Open a terminal, and navigate to, or create a directory you wish to contain the repo.
3. Once in the inside the desired directory, use the command `git clone` followed by this url, "https://github.com/DrWatson0814/           paranormal-frontiers.git".
4. After the repo as been cloned, in your terminal, enter the command `npm install`. This will install the needed dependencies.
5. Next, in the terminal, enter the command `npm run dev`. This will start the web server.
6. Finally, open the browser of your choice and in the address bar input, localhost:8080 and press enter.

## <u>Usage:</u>
    Navigation is done using the various links. On the Research page, enter in the desired paranormal search query and either press enter or click on the begin button to commence the search. The Gear and Investigation pages are still under construction.
